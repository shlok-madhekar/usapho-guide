# USAPhO Guide

A free course for the F=ma exam and the US Physics Olympiad: the topics in the
order they build on each other, with worked lessons, simulations and the
problems worth doing attached to each one.

**Live at [usapho.one](https://usapho.one).**

## Contributing

Anyone can write a lesson, add a problem or build a simulation.

- **From the site:** open [usapho.one/edit](https://usapho.one/edit), connect
  GitHub, and your change arrives here as a pull request under your own account.
- **From git:** fork the repo and open a pull request as usual. See
  [SETUP.md](SETUP.md) for running it locally.

Everyone with a merged change is listed at
[usapho.one/contributors](https://usapho.one/contributors).
